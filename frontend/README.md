# Algo Trading Frontend

Next.js + TypeScript + Tailwind foundation for the professional web terminal.

## Phase 1 scope

- Responsive application shell
- Desktop sidebar + mobile navigation
- Shared design tokens and reusable UI primitives
- Route scaffolding for the final dedicated pages
- API/WebSocket environment configuration
- Paper-safe indicator; real broker orders remain disabled
- No replay functionality
- No fake market data

The existing `web/dashboard/` is intentionally retained during migration and is not deleted by this phase.
