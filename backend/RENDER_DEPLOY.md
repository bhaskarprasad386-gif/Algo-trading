# Render deployment

This backend is deployed as a Render Web Service from the repository `main` branch.

- Root directory: `backend`
- Runtime: Python 3.11
- Build: `pip install -r requirements.txt`
- Start: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
- Health check: `/`
- `SECRET_KEY` is generated by Render and must not be committed.

After the Render service is created, verify the service URL at `/` and `/docs` before pointing the Android APK to it.
